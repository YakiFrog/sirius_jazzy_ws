|---|---|---|---|
| 実速度/指令（追従） | 1.02（常にオーバーシュート） | 1.00 | 追従改善 |
| 蛇行（直進ヨーレート rms） | 0.070 rad/s | 0.040 rad/s | **−43%** |
| 左右輪差 rms | 45.8 rpm | 30.5 rpm | **−33%** |
| 経路横偏差 max | 0.421 m | 0.266 m | **−37%** |

| 速度ディップ（小刻みな減速） | 82 /min | 116–131 /min | 増（トレードオフ） |
| 最低可動速度 | 0.2–0.3 m/s | 0.1 m/s | 低下 |
| 速度・加速度設定値（vx_max 等） | 変更なし | 変更なし | — |

### 補足（トレードオフ）
- 閉ループは**蛇行・左右差・横偏差・回生過電圧を改善**する一方、**速度の
  小刻みな変動（ディップ）は増える**。両者はトレードオフ。
- 速度・加速度の**設定値（`vx_max`/`ax_max` 等）は今回変更していない**。
  差分はドライバの閉ループ制御（FF+PI+スルーレート制限+duty LPF）による。

## 4. オドメトリ校正（5m手押し, 2026-09-25）

電子E-stopでモータを無効化し、機体を**直線5.000m手押し**して `/odom` と比較。

| 項目 | 値 |
|---|---|
| 実距離 | 5.000 m |
| `/odom` 正味変位 | 5.039 m |
| `/odom` 経路長 | 5.043 m |
| **スケール誤差** | **+0.79%** |
| 直線度 (path/net) | 1.0007 |

**結論: `pulse=475`（車輪1回転あたりのカウント）は正しい（誤差1%未満）。修正不要。**
- ドライバは起動時にコントローラへ `^EPPR 1/2 475` を設定しており、オドメトリは正確。
- 以前懸念した「`pulse=475` vs 実測`EPPR=295` の不一致」は**実用上問題なし**と確定。
- 副次効果: ソフト閉ループはオドメトリ基準で**真の速度を正しく追従**している。
- 屋外地図の歪みは**オドメトリのスケール起因ではない**（IMUヨー/磁気、またはrtabmap側の可能性）。
