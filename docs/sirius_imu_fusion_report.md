# Sirius3 IMU・センサフュージョン調査レポート（2026-09-25）

屋外での地図生成時に歪みが見られたため、IMU（姿勢・ヨー）とセンサフュージョンを
調査した。オドメトリのスケールは別途校正済みで**正確（誤差+0.79%）**であり、
歪みの原因ではない（`docs/sirius_speed_spec.md` 参照）。

## 1. 構成
| 項目 | 内容 |
|---|---|
| IMU | HWT905（WT901系, witmotion_ros） |
| 姿勢の生成 | `use_native_orientation: false` → **センサ内蔵AHRSのオイラー角**を使用 |
| 融合 | robot_localization EKF (`ekf_fusion.yaml`) |
| EKF入力 | `odom0`: vx のみ / `imu0`: **yaw（絶対）＋ vyaw（角速度）** / `odom0` vyaw は無効 |
| フレーム | `world_frame=sirius3/odom`, AMCL/SLAMが map→odom を補正 |
| IMUレート | **約20Hz**（`sensor_fusion.launch.py` の `frequency:100` は未実装で無視） |

## 2. 軸モードの調査（9軸 vs 6軸）

HWT905は融合軸モードをレジスタ`0x24`で切替可能（`0x00`=9軸/磁気, `0x01`=6軸/ジャイロ）。

| モード | 静止ヨードリフト | ヨーの性質 | 磁気外乱 |
|---|---|---|---|
| **9軸（磁気）** | **0.000°/60s** | **絶対ヨー** | 弱い（屋外で飛ぶ可能性） |
| **6軸（ジャイロ）** | 0.025°/min | 相対ヨー（起動時基準） | 免疫 |

### 走行比較（同コース 15F-0925）
| 指標 | 9軸 | 6軸 |
|---|---|---|
| IMU-AMCL ヨー差 std | **1.46°** | 1.86° |
| ヨードリフト（vs AMCL） | -1.15°/min | **+2.14°/min** |
| **蛇行 yaw rms（直進時）** | **0.040 rad/s** | **0.111 rad/s（2.8倍悪化）** |

**結論: 9軸（絶対ヨー）が本機では安定。**
- 6軸は静止では安定（0.025°/min）だが、**走行中のジャイロスケール/振動で約2°/minドリフトし、蛇行が2.8倍に悪化**。
- 9軸は磁気参照の絶対ヨーで、屋内走行では AMCL とよく一致（差の変化 -1.3°/70s）。
- → **9軸を維持**（ユーザ所見「9軸でも屋外は行けている」と整合）。

## 3. その他の所見
- **`/magnetometer`は全ゼロ**（`wt905.yaml` の `coefficient: 1e-8` でスケールされ0）。ただしEKFは未使用のため実害なし（診断用に係数修正の余地あり）。
- EKFのヨーは `imu0` の絶対yawに依存（`odom0` vyaw無効）。9軸が安定なので問題なし。
- 屋外地図の歪みは、**オドメトリ・IMUヨーの短時間ドリフトでは説明できない**（両者とも良好）。
  → 残る候補は **rtabmap側のオドメトリ/ループ閉じ設定**、または**特定地点の磁気外乱**。

## 4. 操作方法
```bash
# 軸モード切替（witmotionノード停止中に実行）
python3 other_programs/roboteq_identification/imu_set_axis.py 9   # 9軸(既定)
python3 other_programs/roboteq_identification/imu_set_axis.py 6   # 6軸
# EEPROM未保存のため電源再投入で9軸に戻る
```

## 5. 推奨
1. **9軸を維持**（現状復帰済み）。
2. 屋外歪みが再現するなら、**rtabmapのオドメトリ/ループ閉じ設定**を精査（IMU/odomは無罪のため）。
3. 磁気外乱が疑われる地点では、その場でヨーが飛ばないか確認（必要なら6軸＋SLAM補正を検討）。
