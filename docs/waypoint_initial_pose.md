# 周回時のウェイポイントInitialPose

位置だけ変更して到達時の向きを維持する場合は、`yaw`の代わりに`yaw_mode: current`を指定します。

```yaml
initial_pose:
  x: 6.0
  y: 0.3
  yaw_mode: current
```

WaypointEditorでは「到達後の現在の向きを維持（位置だけ再設定）」を有効にします。
停止後、AMCLへ送信する直前の`map → sirius3/base_footprint`の向きを一度取得します。
新鮮なTFが取得できなければ送信せず待機し、既存のタイムアウトで失敗を通知します。
現在の向きの推定誤差も維持されます。向き自体を修正したい場合は従来の`yaw`指定を使用してください。
既存のウェイポイント設定は自動変換しません。実行中のmv_goalは次回起動時に更新を読み込みます。

最後のWPなどに、任意の地図上の再初期化先を保存できます。項目がなければ実行しません。

```yaml
waypoints:
  - number: 112
    x: 3.0
    y: 4.0
    angle_radians: 0.2
    initial_pose:
      x: 0.0
      y: 0.0
      yaw: 0.0  # rad。これは指定例です。
```

WaypointEditorのAdd Actionsで「到達後に地図上の位置・向きを再設定」を有効にし、
X/Yと向き（画面は度、保存はrad）を入力します。「先頭WPの位置」で先頭WPの座標・向きを
コピーできます。無効な設定はYAMLへ出力しません。既存のルートに自動追加はしません。

`mv_goal`起動時は、ファイル名・周回設定・設定された点数・対象WPと再初期化先を表示します。
周回自体は起動時のループ設定で選択します。WPに設定したアクションは非周回でも実行します。

到達判定は0.5m。Nav2の現在のゴールをキャンセルし、Odom TFで静止を確認後、
AMCLの`/set_initial_pose`サービスへだけ送ります。地図とAMCLが準備済みであること、
新しいAMCL姿勢3回とTFが指定位置付近であること、Odomが連続であることを確認してから
次のWPへ進みます。最終WPでループが有効なら先頭へ戻ります。

30秒で確認できなければ、次のゴールを送らず待機し、ログへ失敗理由を表示します。
状態を確認したうえで`/nav_control`の`resume`で再試行、`cancel`で中止できます。
電子緊急停止や駆動指令の送信には使いません。失敗時に勝手に電子停止を解除もしません。
占有セル・未知領域・地図範囲外への再初期化は拒否します。
`wait_time`は再初期化確認後に実行します。`change_map`と`initial_pose`は同じWPへ指定せず、
別WPに分けてください。地図切り替え既存処理もAMCL専用の確認シーケンスを使用します。

## 移動後のInitialPoseがずれる問題

`rosbag_20261024_153828`の15:39:34で、AMCLは指定位置(-0.042,-0.001)を受理。
約0.204秒後、同じ`/initialpose`を受けた旧`ekf_pose_initializer`がEKFをリセットし、
Odomが約6.917m飛んでいました。この間、車輪Odomは変化していません。
後続のInitialPoseでも7.147m、4.797m、3.570mのOdomジャンプを確認しました。
AMCLはこれを実移動として取り込むため、粒子群が指定位置から移動します。

対策として、sf_realでEKF Pose Initializerを自動起動しない構成にしました。
地図上の`/initialpose`はAMCLにだけ作用させ、ローカルOdomをリセットしません。
明示的にEKFをリセットする場合は`start_ekf_pose_initializer:=true`で補助ノードを起動し、
`/ekf/initialpose`へ`sirius3/odom`フレームのPoseを送る別操作が必要です。
mapフレームでのEKFリセットは拒否します。

車輪エンコーダの累積値や、ローカルOdomがゼロでないこと自体は異常ではありません。
AMCLはmap→odomで地図上の位置を調整するため、回転数をゼロにする必要はありません。

Desktopの隔離domain 221で、実AMCLを使い非ゼロOdom・移動後の地図差し替え・
AMCL再起動・手動InitialPoseを確認しました。EKFリセット呼び出しは0回。
合成Scanでの確認であり、実センサーによる修正後の実機走行確認は別途必要です。
