# SiriusLauncher 操作画面

上部は顔画面の小さなプレビューと走行準備状態を横並びに表示します。デスクトップは約72px、スマホは2段で約93pxの高さです。
顔を押すと顔・耳の操作パネル、走行状態を押すと走行診断を開きます。詳しい理由は走行診断で確認します。
狭い画面では電源出力の詳細を「その他」にまとめます。
電子停止と物理停止の表示はそれぞれの最新テレメトリを使います。物理停止は駆動電圧からの推定です。
停止表示を押すと既存の詳細パネルを開きます。停止の切り替えは詳細パネルで明示的に操作します。

Homeは稼働中一覧、クイックスタート、システム使用率を中心に表示します。
クイックスタートの用途ボタンは既存の用途フィルターと連動し、「起動」ボタンでのみ起動します。
ログとプロセスのメニューは各行の右側に並べています。「プログラム一覧」から個別のコマンドを探せます。
左右の幅は引き続き調節でき、保存済みの幅を復元します。初回の右側の幅は40%です。

スマホは一列で表示します。下部のメニューを横にスワイプすると全タブにアクセスできます。
タブレットの縦持ち・横持ち、スマホの横持ち、ライト・ダークモードに対応します。

表示層は `static/operations_refined.js` と `static/operations_refined.css` です。
状態の判定、プロセス操作、テレオペ、停止コマンドは既存の実装を使用します。

## PWAの画面端

外枠の `shell.html` は `viewport-fit=cover` と `safe-area-inset-*` を使って、ステータスバー・ホームバーの保護領域を確保します。
埋め込んだ画面では二重に余白を取らず、`/console` を直接開いた場合は本体側で保護領域を確保します。
外枠の背景色とtheme-colorは本体のライト／ダークモードに追従します。
外枠やviewport設定の更新後はPWAを完全に閉じて開き直してください。OS固有のぼかしの描画は実機で確認が必要です。

スマホ・横持ち時の下部メニューは、角を丸めた半透明のフローティングバーです。
ホームバーの保護領域からさらに10px離し、選択状態を内側のピルで示します。
透明度を下げる端末設定と、背景ぼかし非対応環境では不透明な背景に切り替えます。

顔プレビューの枠は取得画像の縦横比に追従します。ヘッダーは高さを抑え、操作パネルでは画像全体が収まる比率で表示します。
クイックスタートはセットの色、プログラム一覧はタブの色を淡い背景と縁に使います。稼働中・エラーの状態表示も引き続き確認できます。
