# SAM3 部分地図補正

既存のオフラインSAM3地図を残したまま、rosbagの指定区間だけを対象クラスで再推論し、別名の修正版へ意味セルを追加するデスクトップアプリです。

## 操作

1. rosbagと補正元地図ディレクトリを選びます。
2. 開始・終了スライダーを動かし、瞬時に表示されるカメラ画像で区間を探します。
3. 対象クラスを1つ以上チェックし、プレビュー対象ごとの閾値を指定します。
4. 必要な場合だけ「開始位置をSAM3プレビュー」でマスクと採用スコアを確認します。
5. 区間全体を確認する場合は「開始～終了をSAM3プレビュー作成」を押します。
6. 「この区間を再推論して新しい地図を作成」を押します。

区間プレビューは、指定した推論間隔（0.5/1/2/5秒）で結果を一時キャッシュします。作成後は再生・一時停止・シークと、1/2/4/8 fpsの動画風再生ができます。作成途中でも、完了済みフレームは確認できます。

「プレビュー名追加」には `curb`、`crosswalk`、`person` など任意の英語プロンプトを追加でき、次回起動時にも保持されます。追加名は1フレーム・区間プレビュー用です。意味地図へマージできるのは、クラスIDが定義済みの `tactile paving`、`grass`、`roadway`、`sidewalk` です。

意味クラス名とSAM3へ渡す推論文は分離されています。`tactile paving` の既定推論文は `line type tactile paving` で、推論結果は意味ID 4（黄色）として保存されます。「現在クラスの推論文」で表現だけを変更しても、意味地図上のクラスIDは維持されます。

「スライダー停止後にSAM3も自動実行」は既定でOFFです。ONにすると操作停止から700ms後にSAM3を実行します。位置探しだけならOFFのままにしてください。

元のrosbag・地図は上書きされません。補正は対象クラスの追加のみです。処理中は同じport 8080を使うUnityやオンラインSAM3を起動しないでください。

地図生成時のSAM3閾値は0.20未満を禁止しています。また、`tactile paving` が部分地図の観測領域の35%を超えた場合は、巨大な誤検出マスクと判断してマージ前に安全停止します。通常は0.40～0.50で区間プレビューを確認してください。
